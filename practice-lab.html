Essential Systems Knowledge

OST Notes: Operating Systems & Core Architecture

Curated architectural blueprints, operating system mechanisms, and Linux commands essential for software, DevOps, and cloud engineers.

1. Kernel vs User Space & System Calls

Modern operating systems enforce memory and hardware protection through dual CPU modes: Ring 0 (Kernel Mode) with direct hardware access and Ring 3 (User Space) for application binaries. User programs safely request privileged OS services via software interrupts known as System Calls.

Key Syscalls: fork() | execve() | open() | read() | write() | waitpid()

2. Process Lifecycle & CPU Scheduling

Processes cycle through distinct states: Ready → Running → Blocked/Waiting → Terminated. The Linux Completely Fair Scheduler (CFS) allocates CPU time slices using Red-Black trees based on process "nice" priority values (ranging from -20 highest priority to +19 lowest priority).

Commands: ps aux --sort=-%cpu | top | nice -n 5 cmd | kill -9 <PID>

3. POSIX Permissions & Access Security

Linux implements granular security using three privilege levels: Owner (u), Group (g), and Others (o), calculated with octal weights for Read (4), Write (2), and Execute (1). Special permission bits (SUID, SGID, Sticky Bit) safeguard sensitive binaries and shared directories.

Commands: chmod 755 app.sh | chown -R www-data:www-data /var/www | umask 022

4. Streams, Pipelines & Text Processing

The Unix philosophy connects simple utilities into versatile pipelines using standard data streams: Standard Input (stdin: 0), Standard Output (stdout: 1), and Standard Error (stderr: 2). Efficiently inspect, search, and parse gigabytes of server logs in milliseconds without memory overhead.

Commands: grep -rnI "ERROR" /var/log/ | awk '{print $1, $5}' | sort | uniq -c
